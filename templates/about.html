Project Goal

To build an AI-powered web application that detects plant diseases from leaf images using deep learning, helping farmers and gardeners quickly identify and treat plant diseases before they spread.

🧠

CNN Architecture

The model uses a deep CNN with multiple Conv2D layers, MaxPooling, Batch Normalization, Dropout layers, and Dense classification layers. Input size: 224×224×3 RGB images.

📊

Dataset

Trained on 15,000+ plant leaf images from the PlantVillage dataset, augmented using rotation, flipping, zoom, and brightness adjustments across 10 disease categories.

⚡

Performance

Achieved ~93% validation accuracy using Adam optimizer with learning rate scheduling, early stopping, and data augmentation techniques to prevent overfitting.
